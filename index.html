Cara dapat konfigurasi Firebase
  1. Buka console.firebase.google.com, login pakai akun Google.
  2. Klik Add project → beri nama ananda-kayu → Continue → matikan Google Analytics → Create project.
  3. Menu kiri: Build → Firestore Database → Create database → lokasi asia-southeast2 (Jakarta) → mulai dengan test mode.
  4. Masuk Build → Authentication → Get started → tab Sign-in method → aktifkan Anonymous.
  5. Klik gerigi → Project settings, gulir ke bagian Your apps, klik ikon </> (Web), beri nama apa saja → Register app.
  6. Muncul kode berisi apiKey dan projectId. Salin mulai tanda { sampai }, tempel ke kotak di atas.
  7. Isi Kode Sinkron sesukamu (huruf kecil dan angka, tanpa spasi), lalu tekan Hubungkan.
  8. Di perangkat lain: tempel konfigurasi yang sama dan Kode Sinkron yang sama persis.

Kalau sudah jalan, amankan: Firestore → Rules, ganti isinya jadi allow read, write: if request.auth != null; lalu Publish.
