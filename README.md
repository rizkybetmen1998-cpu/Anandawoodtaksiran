# Ananda Kayu — Taksiran & Laba

Aplikasi web untuk menaksir harga beli tebangan kayu (Albasia & kayu keras),
mencatat biaya operasional, dan menghitung laba per tebangan.

- Tayang di: https://anandawood.vercel.app
- Setiap perubahan yang masuk ke branch `main` otomatis dipasang oleh Vercel.
- Data tebangan tersimpan di perangkat (dan Firebase bila sinkron aktif), bukan di repo ini.

## Isi
- `index.html` — seluruh aplikasi
- `manifest.json`, `icon-*.png` — supaya bisa di-install di HP seperti aplikasi
